## Frame timing: important confound, not an invented defect

The instrumented full journey's typical frame medians were approximately **31.1–31.3 ms**, with per-document p95 values about **34.0–40.1 ms**. It also recorded isolated **1,116.9 ms** and **628.9 ms** gaps during camp greeting and armour refusal. The run included video/audio recording, event-triggered screenshots and another diagnostic browser at some points; those gaps cannot be assigned to game logic or shader compilation from that trace alone.

Two separate fresh-Chrome checks replayed the armour-refusal sequence from an explicitly reducer-built seven-objective local checkpoint using real entry/action input, with **no video, MediaRecorder or screenshots during play**. Their largest in-sequence gaps were **29.8 ms** and **27.8 ms**. The 628.9 ms stall did not reproduce in those checks. This reduces confidence in treating the capture outlier as a game defect; it does not prove every device/network or the camp's distinct outlier is hitch-free. [Probe results](evidence/msr01-2026-11-19/hitch-probe/summary.json).

Keep capture overhead in mind and perform a clean, matched performance test if a user-visible hitch can be reproduced. Do not start another shader/renderer rewrite based on this diagnostic capture.

## Recommended implementation order

1. **MSR-02:** address the reproduced long holds in D01/D02 through explicit looping-listener, sustained-speech and one-shot policies. Preserve the authored carry/action contacts, rig scale and combat timing. Capture controlled start/stop/turn/foot-contact comparisons while tuning movement.
2. **MSR-03:** use the continuing David–Saul answer as the reference; polish the affected instructions/responses and D04/D05. Obtain an audible line-specific review before replacing any voices.
3. **MSR-04:** build the **Eliab → walk → Saul** connection against the confirmed current objective. Validate load/reload, input reset, sound activation and chapter-review isolation before broader rollout.
4. **MSR-05/06:** apply the reviewed route/performance pattern to the remaining gaps and cast, then repeat the full journey and responsive checks.

These limits do not prevent starting the measured motion fixes in MSR-02.
