# Q02 David and Jesse exchange plan

Use the tested David and Jesse assets to rehearse the errand in a standalone Godot scene. Keep the [visual brief](../quality-review/david-jesse-visual-brief.md#blocking-and-shot-beats) for the story and order of the exchange. This rehearsal uses fixed actor marks and a nearby table so the pickup can be checked without village navigation.

1. Author David's relaxed listening loop, his glance toward the provisions, a nod of acknowledgement and a two-handed reach, lift and settle. Preserve the existing walk and check the tuned poses for planted feet, hand contact and clothing clearance.
2. Save the new Blender source and export David to GLB. Import it alongside Jesse's existing asset and confirm that each actor plays independently in Godot. Match the table bundle to the pickup pose and transfer it to David at contact.
3. Run the conversation from one Speak action. Jesse greets and points while David listens, glances and nods. Return input for a separate Take action, then play the pickup through to a stable carry pose.
4. Test the complete exchange at 5.5 m and 2.7 m in Godot and Chrome. Record gesture readability, prop contact, reset behaviour and remaining art issues. Leave village integration, collision-safe alignment and control handoff for Q04.
